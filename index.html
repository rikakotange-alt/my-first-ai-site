About This Shelf

この研究棚について

Rika Creative Codexは、完成した答えを並べる場所ではありません。AI学習の途中で生まれた問い、気づき、試行錯誤、対話、図解、制作ログを、あとからたどれる形で少しずつ収蔵していく小さな研究棚です。

完成品だけでなく、考え方が変わった瞬間も

ここに置いてあるものは、完成品だけではなく、考え方が変わった瞬間や、うまくいかなかった試作も含まれています。

知識を、体験で自分のものにする

このCodexは、知識を集めるだけの棚ではありません。知識が体験へ、体験が気づきへ変わる過程も残していきます。

Learning OS

評価される学びから、自分を助ける学びへ

AI学習では、知識を評価されるためのものではなく、自分を助ける道具として扱いたい。間違えないために学ぶのではなく、試しながら、自分の世界を少しずつ広げるために学ぶ。

今の学び方

受け取る → ChatGPTと対話する → 自分の世界へ翻訳する → 試す → 図解や制作物にする → Codexへ残す。

枝分かれしても、根っこではつながっている

Work実験ログ、Human OS研究カード、Notionテンプレートのように、作業や分類は別々の枝へ分かれていきます。ただ、その根には「学ぶ → 試す → 観察する → 意味を考える → 型にする → 残す」という同じ流れがあります。

🐾 パウ所長の研究メモ

棚では別々に見えても、根っこは同じ学びから伸びているワン。枝だけでなく、つながりも残しておくワン！
