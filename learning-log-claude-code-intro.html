Learning Log

Web制作の役割が見えてきた

2026.07.05

Claude Code入門を見終えて、Web制作の基礎棚を作った

DMM AI生成CAMPの「Claude Code入門」を見終えて、Web制作まわりの理解がかなり整理された。

今回いちばん大きかったのは、「難しい仕組みを全部覚える」ことよりも、「何がどの役割なのか」を見分けられるようになったこと。 そして、自分の使いやすい作業環境に置き換えて考えられるようになったこと。

私は普段からChatGPT Plusを使っているので、講座で出てくるClaude Codeの内容を、そのまま受け取るのではなく、「Codexならどう使うか」という視点に置き換えながら見ていった。

最初は、「サイトを作る」ことと「公開する」ことがごっちゃになっていた。 GitHubに保存することと、GitHub PagesやCloudflare Pagesで公開することの区別も、まだはっきりしていなかった。

でも、一つ一つの役割を分解し、料理や飲食店にたとえて考えることで、かなりイメージしやすくなった。

作る。保存する。公開する。 この3つは、それぞれ別の役割だった。

AIは作る。GitHubは保存する。Pagesは公開する。 この役割分担が見えたことで、Web制作の全体像が一気につながった。

Codex Direction

Codexを知の図書館へ育てる

今回の学びは、単なる講座理解で終わらず、自分のCodex運用の方向性にもつながった。

Codexは、長いスクロール型の記録帳ではなく、学習ログ・研究カード・構造図を整理し、あとから再検索できる「知の図書館」「自分専用アカデミア」として育てていきたい。

表側は、整理されたカードを探せる検索端末図書館。 裏側は、日々のメモ・未整理カード・振り返りを受け止める研究秘書アプリ。 そんな二層構造が、自分の今の制作テーマとかなり噛み合っている。

Learning Drive

わかることが増えて楽しい

6月10日にDMM AI生成学び放題に申し込んでから、CapCut、NotebookLM、Canva、Codex、Claude Code、AI動画制作、ゼミ課題と、毎日のように学びを積み重ねてきた。

その中で、「昨日できなかったことが、今日はできる」という喜びと体験が、少しずつ増えている。

以前は「何から学べばいいんだろう？」と思って悩んでいた時期もあった。けれど、今は少し違う。

学ぶこと自体が楽しくなっていて、収益のためだけではなく、「世界の見え方が変わるのが面白い」と感じるようになってきた。

特に印象に残っているのは、自分の中に出てきたこの感覚。

「わかることが増えて楽しい！」

誰かの評価や反応より先に、知ることそのものが楽しい。 この感情は、これから世界がどれだけ変わっても、自分の一番強い原動力になっていくと思う。

Iteration

公開はゴールではなくスタート

そして、サイトの公開はゴールではなくスタートだと思う。 サイトは公開して終わりではなく、実際に使いながら育てていくものだ。

「ここが見にくい」 「この情報を追加したい」 「このカードをもっと探しやすくしたい」

そう気づいたところを、Codexに指示して、少しずつ改善していく。

公開する。自分で使い倒す。気づいたことを修正する。機能を追加する。また更新する。

この繰り返しで、自分もサイトも少しずつ育っていく。

今は、「完璧に作る力」よりも、「公開して改善し続ける力」を育てる段階なのだと思う。

この学習サイトが、自分にとっても、いつか誰かにとっても役に立つ場所になるといい。 そんな未来に想いを馳せながら、色々試し、直し、積み重ねて、Codexを知の図書館として育てていきたい。

🐾 パウ所長の研究メモ：公開は完成の旗ではなく、観察開始のベルだワン。使って、直して、また育てる。Codexは動く研究棚になっていくワン。
